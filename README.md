# The Eighty V2.3

This update rolls in the current approved changes.

## Included
- Brand text standardized to **The Eighty**.
- Title Case standardized across headers and statement labels.
- Fitness is now **Intentional Movement**:
  - Target: 45+ minutes of intentional fitness or movement.
  - Minimum: 10–15 minutes of movement, mobility, stretching, drills, or recovery work.
- Fitness and the 100-mile challenge are separate.
- The 100-mile challenge is fed by qualifying walking/running workouts.
- Apple Fitness screenshot card redesigned with a richer visual treatment.
- Screenshot reading attempts to capture:
  - Workout Type
  - Workout Time
  - Distance
  - Avg. Pace
  - Total Calories
  - Date
- Added **Workout History**.
- Added manual workout entry.
- Saved workouts can be edited or deleted.
- Deleting a qualifying walk/run removes that distance from the 100-mile total.
- Duplicate workout warning added.
- Bottom navigation now uses one consistent modern outline icon style.
- Existing hero, mountain treatment, approved logo watermark, The Path, WHY logic, and progress system are retained.
- Service-worker cache bumped to `the-eighty-v2-3`.

## Upload These Files To The GitHub Repository Root
1. `index.html`
2. `manifest.webmanifest`
3. `service-worker.js`
4. `apple-touch-icon.png`
5. `icon-192.png`
6. `icon-512.png`

`the-eighty-logo-transparent.png` is included for future design work but is not required separately for the current embedded hero.

## After GitHub Pages Deploys
1. Fully close The Eighty Home Screen app.
2. Reopen it.
3. If iOS still shows an older version, refresh the Safari page once or remove/re-add the Home Screen shortcut.
